Build a full-stack web application called "Team Task Manager" with modern UI and complete backend functionality.

Core Requirements:
- Authentication system with signup and login
- Role-based access control with two roles:
  1. Admin
  2. Member

Features:
1. User Authentication:
   - Secure signup/login
   - Session handling
   - Role assignment (Admin/Member)

2. Project Management:
   - Admin can create, edit, and delete projects
   - Each project can have multiple team members
   - Members can view assigned projects

3. Team Management:
   - Admin can add/remove users from projects
   - Assign roles within project if needed

4. Task Management:
   - Create tasks inside projects
   - Assign tasks to specific users
   - Task fields:
     - Title
     - Description
     - Status (To Do, In Progress, Completed)
     - Due Date
   - Members can update task status

5. Dashboard:
   - Show all tasks assigned to logged-in user
   - Display:
     - Pending tasks
     - Completed tasks
     - Overdue tasks
   - Clean visual summary (cards or charts)

6. Backend & API:
   - Build REST APIs for all features
   - Proper data relationships:
     Users ↔ Projects ↔ Tasks
   - Use a database (preferably PostgreSQL or similar)
   - Ensure validations and error handling

7. UI/UX:
   - Clean modern UI (like a SaaS dashboard)
   - Responsive design (mobile + desktop)
   - Sidebar navigation (Dashboard, Projects, Tasks)

8. Tech Requirements:
   - Full-stack implementation (frontend + backend)
   - Use a scalable structure
   - Environment variables support

9. Deployment Ready:
   - Prepare the app for deployment on Railway
   - Include clear setup instructions
   - Ensure app runs with one command

10. Output Requirements:
   - Generate complete working code
   - Include README with:
     - Setup steps
     - Environment variables
     - Deployment instructions (Railway)
   - Ensure code is GitHub-ready

Bonus (if possible):
- Notifications for overdue tasks
- Activity logs
- Simple charts on dashboard

Important:
- Keep the app simple but fully functional
- Prioritize working features over complexity
- Ensure no broken flows
